# PETCH

반려동물과 함께 갈 수 있는 식당·카페를 찾는 검색 웹사이트입니다.
RUNCH(점심 추천 서비스)와 동일한 UI 스타일로 제작했습니다.

## 현재 상태
- 정적 HTML/CSS/JS 한 파일(`index.html`)로 동작하는 데모입니다.
- 식당·카페 데이터는 예시(mock) 데이터이며, 지도는 실제 지도 API 없이 그린 예시 이미지입니다.
